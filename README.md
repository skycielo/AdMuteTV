# AdMuteTV

**Mute commercials. Automatically detects and silences ads.**

AdMuteTV is a lightweight Android TV app designed to give viewers control over their experience. It monitors TV content in real time and automatically mutes audio during commercial breaks, then restores volume when the show returns — no remote needed.

---

## 🔧 Features

- Automatic commercial detection
- Smart mute/unmute logic
- Designed for Android TV and Fire TV
- Simple, clean on-screen interface
- One-time setup — runs in the background

---

## 🚧 Status

This is an active work-in-progress. The initial version will include:
- Manual mute toggle (MVP for testing)
- Timed detection logic
- Basic visual feedback

Planned features:
- Smarter ad detection (logo fades, audio dips, time patterns)
- Optional Firebase logging for mute/unmute history
- Support for user settings and alerts

---

## 📂 Project Setup

1. Clone this repo
2. Open in Visual Studio Code
3. Build the project using Android Studio or command-line tools
4. Deploy to an Android TV device or emulator
